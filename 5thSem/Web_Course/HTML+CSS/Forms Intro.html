1. Basic Form Structure

Form Attributes:

  • action - Where the form data is sent
  • method - GET (Data is visible in URL (e.g., ?name=john&email=john@example.com)) or POST (Data is hidden in request body)
    • Get is used for searches, filters
    • Post is Used for login forms, sensitive data, file uploads
  • name - Identifies the form
