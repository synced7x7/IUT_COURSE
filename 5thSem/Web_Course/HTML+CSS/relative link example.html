What is a Relative Link?

A relative link points to a file within the same website or directory structure, without specifying the full web address.

Examples of Relative Links:

  • <a href="about.html">About</a> - Same folder
  • <a href="pages/contact.html">Contact</a> - Different folder
  • <a href="../index.html">Home</a> - Parent folder

Relative vs Absolute Links

Link Type Example Use Case
Relative about.html Links within the same website
Absolute https://www.google.com Links to external websites
