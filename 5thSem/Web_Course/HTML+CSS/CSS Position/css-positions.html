🎯 CSS Positioning - The 5 Types

1. Static (Default)

Elements flow normally in the document. top, right, bottom, left and z-index have NO effect.

2. Relative

Positioned relative to its normal position. Other elements don't adjust to fill the gap.

Positioned relative to nearest positioned ancestor. Removed from normal document flow.

4. Fixed

Positioned relative to viewport. Stays in same place even when scrolling.
