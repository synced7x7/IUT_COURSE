Port Address: 0FFFFh
Operation: I/O WRITE → M/IO̅ = LOW
Wait States: 4× TW
Interrupt Flag: SET → S6 = 1
Segment Register: DS → S4=0, S3=1
Total Cycles: 8 × 200ns = 1600ns @ 5MHz

WRITE Bus Timing (Complete BUS Cycle — I/O Write with 4 Wait States)

8086 · OUT to Port 0FFFFh · IF=1 (S6=1) · DS in use (S4=0, S3=1) · 4 WAIT States inserted

Bus Timing for I/O Write Operation — 8086 @ 5MHz

① Port = 0FFFFh → I/O operation:
M/IO̅ stays LOW the entire bus cycle. Port address FFFFh appears on AD₁₅-AD₀ during T1. Upper address lines A₁₉-A₁₆ = 0000 (unused in I/O).
② 4 Wait States (TW×4):
READY sampled LOW at end of T2 → TW₁ inserted. READY checked every clock → remains LOW → TW₂, TW₃, TW₄. READY goes HIGH before T3 → normal execution resumes.
③ Interrupt Flag SET (IF=1):
During status phase (T2–T4), S₆ = 1 appears on A₁₉/S₆ line. This reflects that the CPU's Interrupt Enable Flag is currently SET, meaning maskable interrupts are enabled.
④ DS Register in use:
Status bits S₄=0, S₃=1 appear on A₁₇/S₄ and A₁₆/S₃ lines. This encoding (01) indicates DS is the active segment register for the current data access operation.
⑤ DT/R̅ = HIGH (Transmit):
Since this is a WRITE, the CPU transmits data outward. DT/R̅ stays HIGH (Transmit mode) from T1 through T4, directing the 8286/8287 transceiver to send data to the port.
⑥ WR̅ trailing edge = write commit:
WR̅ goes LOW at T2 and stays LOW through all 4 TW states and T3. The rising edge (LOW→HIGH) at the end of T4 is the moment data is officially written to the output port.
